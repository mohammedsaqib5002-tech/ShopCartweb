🛍️ ShopKart – E-Commerce Website

📌 Project Overview

ShopKart is a responsive e-commerce website developed using React. It provides users with an easy and convenient online shopping experience, allowing them to browse products, search, filter, add products to their cart, manage favourites and complete the checkout process.

🎯 Problem Statement

Traditional shopping requires customers to visit physical stores to explore and purchase products. ShopKart aims to provide a convenient online shopping platform where users can explore different products and manage their shopping activities from one place.

💡 Key Features

- Home Page: Displays featured products.
- Products Page: Browse products from different categories.
- Search: Search products by name.
- Category Filtering: Filter products based on categories.
- Price Filtering: Find products within a selected price range.
- Sorting: Sort products by price and ratings.
- Product Details: View product information, images and ratings.
- Shopping Cart: Add, remove and update product quantities.
- Favourites: Save and manage favourite products.
- Checkout: View order total and place orders.
- Order Success: Confirmation after placing an order.
- Responsive Design: Supports different screen sizes.

⚙️ Installation and Setup

1. Clone the repository:

git clone https://github.com/mohammedsaqib5002-tech/ShopCartweb.git

2. Open the project folder:

cd ShopCartweb

3. Install dependencies:

npm install

4. Start the development server:

npm run dev

5. Open the local URL displayed in your terminal.

🔗 API Used

DummyJSON API is used to retrieve product information and display products dynamically.

API: https://dummyjson.com/products
